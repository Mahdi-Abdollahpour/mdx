# ext/neural_rx

Modified copy of the `utils/` and `scripts/` folders of NVIDIA's
[neural_rx](https://github.com/NVlabs/neural_rx) (NVIDIA License, see
`LICENSE.txt` in the repository root). The files keep their original NVIDIA
headers; modifications add the MDX and DeepEcho receivers, block-graph
training, additional channel models and evaluation utilities.
